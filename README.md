# Приложение ERP система.

### Будет выполнять следующие функции.

1. Задачи по дням для конкретного пользователя.
2. Хранить данные по продажам (Дата и время, Наименование товара, рецепт, сумма полная, сумма аванса, сумма оплаты наличными, сумма оплаты по карте, сумма оплаты по SBP).
3. Каждый день месяца в себе так же хранит имена работников в смене.
4. Ведется подсчет общей суммы внесенных средств (именно из полной суммы).
5. Сумма Денежных средств в кассе на утро и на вечер.
6. Операции по кассе и их сумма (инкассация, приход, доплата).
7. В программе будет график, в отдельной вкладке.
8. Таблица бонусов (в ней будет вестись подсчет бонусов от заказов и продаж).
9. Конверсия, расписанная по дням (в ней хранится количество вошедших клиентов, количество продаж, количество заказов, количество проведённых диагностик, товарооборот относительно дней. Так же ведется расчет конверсии относительно прошлого года, конверсия относительно прошлого месяца и конверсии относительно прошлой недели).
10. Данные плана на текущий месяц по заказам и товарообороту и их выполнение (так же расчет плана на день и его выполнение, а так же остаток плана для выполнения на месяц).
11. Анализ дней недели (какие дни в месяце оказались наиболее продуктивными, исчисление в сумме продаж).
12. Заметки к конверсии.
13. Отдельный расчет заработной платы в отдельности на каждого сотрудника.
14. Подсчет и перечисление реализованных позиций с определенным наименованием, за месяц и вывод в отдельную таблицу.
15. Отдельно подсчет количества позиций с одинаковым названием.
